# 기안메이트 확장프로그램 (크롬 · 엣지)

기안메이트 웹앱에서 만든 기안서를 **하이웍스 전자결재 작성화면에 자동 입력**해주는 브라우저 확장입니다.

## 설치 방법 (크롬 / 엣지 공통)

1. 크롬 주소창에 `chrome://extensions` (엣지는 `edge://extensions`) 입력 후 이동
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭
4. 이 `extension` 폴더를 선택

설치 끝. 브라우저 재시작 필요 없습니다.

## 사용 방법

1. 기안메이트에서 명세서 업로드 → 기안서 미리보기까지 진행
2. **[하이웍스에서 기안 열기]** 버튼 클릭 → 하이웍스가 새 탭으로 열림
3. 하이웍스 **전자결재 > 지출결의서 작성** 화면으로 이동
4. 우측 하단에 뜬 **기안메이트 패널**에서 **[제목·본문 자동 입력]** 클릭
5. 세금계산서 첨부 + 결재선 확인 후 **직접 [기안하기]** 클릭

## ⚠️ 자동화 범위

| 항목 | 자동 |
|------|:---:|
| 제목 | ✅ |
| 본문 표·비고 | ✅ |
| 결재선/참조 | 패널에 안내 (하이웍스 "기본 결재선" 저장 권장) |
| 세금계산서 첨부 | ❌ 직접 (브라우저 보안상 불가) |
| 최종 기안하기(상신) | ❌ 직접 (검토용) |

## 설정: 우리 웹앱 주소 등록

`manifest.json` 의 `content_scripts` 첫 번째 `matches` 에 **배포된 웹앱 주소**를 추가하세요.
현재는 `localhost:3000` 과 `*.vercel.app` 이 등록돼 있습니다. 자체 도메인을 쓰면 아래처럼 추가:

```json
"matches": [
  "http://localhost:3000/*",
  "https://*.vercel.app/*",
  "https://내도메인.com/*"
]
```

## 하이웍스 화면이 바뀌어 자동입력이 안 될 때

`content-hiworks.js` 의 `findTitleInput()` / `findEditor()` 함수의 셀렉터만 실제 화면에 맞게 조정하면 됩니다. (제목 input, 본문 에디터를 찾는 규칙)
