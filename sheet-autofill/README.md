# 작업지시서 자동입력 (크롬 확장프로그램)

노션 **제품DB**에서 상품을 찾아 **상품명 · 담당자 · 생산공장 · 컬러/사이즈별 발주수량**을
**작업지시서 구글 시트**에 자동으로 채워줍니다.

**팀원은 키 입력 없이 `@openhan.kr` 구글 계정으로 로그인만 하면 됩니다.**

```
[확장프로그램] ──구글 로그인 토큰──▶ [회사 대시보드 서버 /api/sheet-autofill] ──노션 키──▶ 노션
      │                                  (@openhan.kr 계정만 통과)
      └──────────── 구글 시트 API로 작업지시서에 직접 입력
```

| 노션 | → | 작업지시서 칸 |
|---|---|---|
| 제품명 | → | C5 |
| 담당자 (써니 → 김진선 등 한글 이름으로) | → | M4 (결재 '담당' 아래) |
| 생산공장 | → | D5 (작업처 아래) |
| 발주DB의 컬러/사이즈별 발주수량 | → | E23:E26 컬러, F23:J26 수량 (F22:J22 사이즈 머리글에 맞춤) |

---

## 팀원: 설치 & 사용

1. 관리자에게 받은 `extension` 폴더를 PC에 저장
2. 크롬 `chrome://extensions` → **개발자 모드** 켜기 → **압축해제된 확장 프로그램을 로드합니다** → `extension` 폴더 선택
3. 퍼즐 아이콘 🧩 → **작업지시서 자동입력**(빨간 원피스) 📌 고정
4. 아이콘 클릭 → 패널에서 **구글 로그인하기** → 회사 계정 선택 → 허용 (처음 한 번)

**사용할 때마다**

1. **입력할 작업지시서** 칸에 새 작업지시서 구글 시트 링크 붙여넣기
   (비워두면 지금 크롬에서 열려 있는 시트에 입력, 최근 시트 5개는 목록으로 남음)
2. 상품명 입력 → **불러오기** (시트 C5에 상품명이 있으면 자동)
3. 미리보기 확인 — 넣기 싫은 항목은 체크 해제, 발주 차수가 여러 개면 칩으로 선택
4. **시트에 입력**

- 발주수량은 E23:J26 전체를 새로 씁니다. 잘못 넣었으면 시트 **파일 → 버전 기록**으로 복구.
- 시트에 편집 권한이 있는 계정이어야 합니다.

## 관리자: 처음 한 번 설정

1. **대시보드 서버 배포** — `src/app/api/sheet-autofill/route.ts`가 Vercel에 배포되어 있어야 합니다.
   서버의 기존 환경변수 `NOTION_API_KEY`, `NOTION_DATABASE_ID`를 그대로 씁니다.
   (선택) `SHEET_AUTOFILL_CLIENT_ID`에 아래 클라이언트 ID를 넣으면 이 확장프로그램에서 받은 로그인만 허용합니다.
2. **Google Cloud** (gianmate 프로젝트)
   - Google Sheets API: 사용 설정됨 ✅
   - 클라이언트 > 웹 애플리케이션 > 승인된 리디렉션 URI:
     `https://facidfdkdplmkhopekankbkmaknbbnnn.chromiumapp.org/`
   - 팀원이 모두 로그인하려면 **대상(Audience)이 "내부"**여야 합니다.
3. `extension/config.js`에 `server`(대시보드 주소)와 `google.clientId` 입력
4. `extension` 폴더를 팀원에게 전달 (압축해서 공유)

## 안 될 때

| 메시지 | 해결 |
|---|---|
| @openhan.kr 구글 계정으로 로그인해주세요 | 개인 gmail로 로그인함 → 패널에서 다시 로그인해 회사 계정 선택 |
| config.js에 구글 클라이언트 ID가 없습니다 | 관리자 설정 3번 |
| 서버 오류 / Failed to fetch | `config.js`의 `server` 주소 확인, 대시보드 배포 여부 확인 |
| 구글 로그인 실패: redirect_uri_mismatch | 리디렉션 URI가 위 주소와 정확히 같은지 (끝의 `/` 포함) |
| 이 시트를 편집할 권한이 없거나… | 로그인한 계정에 시트 편집 권한이 있는지 |
| 시트 사이즈 칸에 없는 사이즈 | 노션 사이즈(예: 150)가 시트 F22:J22에 없음 |
| 컬러가 5개인데 시트에는 4칸뿐이에요 | 양식에 줄을 늘리고 `config.js`의 `rows` 수정 |

## 파일 구성

```
extension/
  manifest.json   확장프로그램 정보 (key = 확장프로그램 ID 고정용, 지우지 마세요)
  config.js       ✏️ 서버 주소 · 구글 클라이언트 ID · 시트 칸 위치
  panel.html/css  사이드패널 화면
  panel.js        화면 동작
  api.js          대시보드 서버 호출 (노션 조회)
  sheets.js       구글 시트 API
  background.js   구글 로그인 처리
src/app/api/sheet-autofill/route.ts   서버: 회사 계정 확인 + 노션 조회
```
